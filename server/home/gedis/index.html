Connect to gedis

gedis is a Redis-compatible data store written from scratch in Go. It speaks the Redis protocol, not HTTP, so talk to it with the official redis-cli or any Redis client:

redis-cli -h gedis.example -p 6380
SET greeting "hello"
GET greeting
INCR visits
ZADD scores 10 ada 7 grace
ZRANGE scores 0 -1 WITHSCORES
INFO server

This is a shared public demo: anyone can read and change what is stored, memory is capped at 32 MB with least-recently-used keys evicted, nothing is saved to disk, and commands that write files or connect elsewhere are switched off.
